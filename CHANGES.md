# Release notes — 1.0.0

First release.

The block lists the OER Exchange's contributors as cards — profile picture,
name, badges, expertise tags, how many resources and courses they have shared,
and how recently. The whole card links to that contributor's profile.

A sort control offers most resources shared, most courses shared, or recently
shared, and a view control switches between cards and a compact list. Both
re-render in place and still work with JavaScript turned off. A footer link
opens the full listing of every contributor.

Only people with something currently published appear, and only those who have
left their profile publicly visible. Co-authors are counted as contributors: a
co-author holds the same rights over a resource as its creator, so they earn
the same recognition.

How many cards to show, which view to use, and which order to open in are all
configurable site-wide and per block instance.

Requires local_oerexchange 2026082200 or later.
